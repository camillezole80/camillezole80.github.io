Assistance

Questions fréquentes

  • Configurer les clés API dans Réglages.
  • Activer ou désactiver la synchronisation iCloud.

Support

Si tu rencontres un problème, merci d’indiquer :

  • Le modèle d’appareil et la version d’iOS, iPadOS, macOS ou watchOS.
  • La version de Vé-RO concernée.
  • Une description courte du bug.
  • Une capture d’écran si possible.
